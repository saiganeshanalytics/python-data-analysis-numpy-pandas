# Python Data Analysis Using NumPy and Pandas

## Project Overview

This project demonstrates fundamental Python data analysis techniques using NumPy and Pandas. It covers array operations, Series, DataFrames, data filtering, aggregation, and data manipulation.

## Objectives

* Perform numerical operations using NumPy.
* Create and manipulate Pandas Series.
* Create and explore Pandas DataFrames.
* Filter data using multiple conditions.
* Calculate category counts and regional averages.
* Update and remove rows and columns.

## Technologies Used

* Python
* NumPy
* Pandas
* Visual Studio Code

## Topics Covered

### NumPy

* Array creation and properties
* Array indexing and slicing
* Mathematical operations
* Minimum, maximum, and mean calculations

### Pandas Series

* Series creation with custom indexes
* Label-based and position-based indexing
* Boolean masking
* Updating and removing values
* Calculating CGPA values

### Pandas DataFrame

* Creating a transactions DataFrame
* Exploring rows, columns, shape, and data types
* Selecting specific columns
* Filtering transactions
* Counting product categories
* Finding unique regions
* Calculating average transaction amounts by region
* Updating transaction amounts
* Adding and removing columns
* Removing rows

## How to Run

1. Install Python.
2. Install the required libraries:

   ```bash
   pip install numpy pandas
   ```
3. Open the project folder in Visual Studio Code.
4. Run `Numpy and Pandas.py`.
